# ハピメア 本体 OP《夢の無限回廊》特效字幕包

## 目录结构

```
本体/字幕制作脚本包/
├── README.md           说明文档
├── config.py           全局参数: 分辨率/24fps/配对金文字体/动态安全区/珠光与水波参数
├── assparse.py         解析 ../op.ass 的句轴、\k 音节、半句气口空格与 `; CN:` 中文译词
├── gen.py              渲染主入口: 组装全片图层并输出 RGBA 裸流
├── preview_line.py     高精度快速预览工具 (trim 滤镜逐帧对齐整片时间轴)
├── render.py           整片一键合成脚本 (管道直连不落中间裸流大文件)
└── effects/
    ├── base.py         2x 超采样哥特珠光渐变字形缓存 + 原生横向正弦水波烟散退场滤镜
    ├── lyric.py        支持左右对齐、气口留白、卡拉OK在唱呼吸高光与水波烟散退场的歌词行层
    ├── apart.py        A 段演出 (L00~L03: 绘本金尘与梦/真双生对照、句尾风化剥落红瓣、一触半透与四色幽冥烛火、凸面黑魔镜水波倒影与永恒滞留)
    ├── bpart.py        B 段演出 (L04~L05: 右上暗丝绒护盾+48.42s红白棋盘菱形切镜波+残影逃逸、左上三女主代表色流转+景子吉他琴弦拨动共振+63.30s纯白过曝消融)
    └── chorus.py       副歌与尾奏演出 (L06~L11 + 2:00 猩红题记: 黄金螺旋入场+双螺旋丝带+咲棱镜彩虹折射、古铜金怀表滴答+彩窗金斑翠绿凤蝶、82.83s白蔷薇碎红瓣+沧蓝幻蝶、舞台追光红线牵引+剪影花瓣爆散、106.92s分形猩红血墨吞噬、尾奏『这是一个甜蜜而又幸福的恶梦故事』原生级内嵌)
```

## 常用命令

```bash
python preview_line.py 0 1 2 3          # 快速预览 A 段
python preview_line.py 4 5              # 快速预览 B 段
python preview_line.py 6 7 8 9 10 11    # 快速预览副歌段
python preview_line.py --span 119.2 125.2  # 快速预览 2:00 尾奏猩红题记
python render.py op_out.mkv             # 渲染整条本体 OP 成片 (输出 op_out.mkv)
```
