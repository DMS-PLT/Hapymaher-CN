使用方法：
把当前目录下的所有文件（含「还原用」文件夹）复制到游戏安装目录
无需转区，直接运行 cmvs32_cn.exe 即可

（「还原用」里是原版 start.ps3 备份，请留着别删，卸载时要用）


卸载方法：
1. 删除本补丁添加的以下文件/文件夹（都在游戏根目录下）：
   cmvs32_cn.exe
   cnpatch.dll
   cnpatch_ui.txt
   TW-Kai-98_1.ttf
   data\pack\script
   data\pack\chip
2. 用「还原用\start.ps3」覆盖游戏目录的 data\pack\start.ps3

   做完这两步，游戏就和装补丁之前完全一样 —— 游戏自带的 cpz 封包
   一个字节都没动过，改的全是外挂文件。
