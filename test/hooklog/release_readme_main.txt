使用方法：
把当前目录下的所有文件复制到游戏安装目录
无需转区，直接运行 cmvs32_cn.exe 即可


卸载方法：
1. 删除本补丁添加的以下文件/文件夹（都在游戏根目录下）：
   cmvs32_cn.exe
   cnpatch.dll
   cnpatch_ui.txt
   TW-Kai-98_1.ttf
   data\pack\script
   data\pack\chip
2. 用「还原用\start.ps3」覆盖游戏目录的 data\pack\start.ps3
