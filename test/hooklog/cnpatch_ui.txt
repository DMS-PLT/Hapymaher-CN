# ── 片段替换（行首加 ~ 表示「整条文字里的任意位置命中就换」）──
# 用于整条会变、但里面有一块固定日文的情况。
#
# 分辨率单选钮显示的是 `1920 x 1080[標準]` 这种：前面跟着 cmvs.cfg 的分辨率列表走
# （标签由游戏 sprintf 出来，共 7 条，实测走 SetDlgItemTextA），后面那块标记是固定的。
# 写死整条不牢靠 —— 换个显示器、改一下 cmvs.cfg 就对不上了，所以只换标记这块。
#
# 实测原始字节（日志里的 SetDlgItemTextA）：
#   31 39 32 30 20 78 20 31 30 38 30 5B 95 57 8F 80 5D
#   当 GBK 读 = 1920 x 1080[昗弨]  ← 屏幕上看到的乱码
#   当 SJIS 读 = 1920 x 1080[標準] ← 真身
~[標準]	[标准]

# ── 运行时填进菜单的两处（实测走 SetMenuItemInfoA + MIIM_TYPE 老写法）──
#
# 画面设置里的分辨率条目：模板里是 `ｳｨﾝﾄﾞｳｽｸﾘｰﾝ(640*480)`，但游戏会按当前显示器
# 重建成 `ｳｨﾝﾄﾞｳｽｸﾘｰﾝ(1920*1080)` —— 分辨率会变，所以只换前面那个词。
# （写死整条的 `ﾌﾙｽｸﾘｰﾝ(640*480)` 在下面整条表里也留着，那两条精确命中优先。）
~ｳｨﾝﾄﾞｳｽｸﾘｰﾝ	窗口模式
~ﾌﾙｽｸﾘｰﾝ	全屏模式
